# Bank Telegram Bot
Telegram-бот для управления пользовательскими профилями и организации денежных переводов.

Проект разработан на Java с использованием Spring Boot и PostgreSQL. Реализованы регистрация пользователей, 
управление персональными данными и обработка пользовательских сценариев с помощью конечного автомата 
состояний (FSM).

Функциональность денежных переводов находится на стадии доработки.

## Список команд
| Команда | Описание |
|:---|:---|
| `/start` | Запуск бота |
| `/restart` | Перезапуск бота |
| `/register` | Регистрация пользователя |
| `/edit` | Редактирование личной информации |
| `/delete` | Удаление аккаунта |
| `/help` | Вывод информации о боте и списка доступных команд |

## Основные возможности
- **Регистрация пользователей:** Создание пользовательского профиля с привязкой к Telegram ID и хешированием номера телефона с использованием SHA-256.
- **Управление профилем:** Изменение персональных данных и удаление аккаунта со связанными данными из базы данных.
- **Управление состояниями (FSM):** Обработка многошаговых пользовательских сценариев с хранением текущих состояний в `ConcurrentHashMap`.
- **Взаимодействие с БД:** Сохранение и получение пользовательских данных с использованием Spring Data JPA и Hibernate.

## Технические ограничения
В текущей реализации логика денежных переводов представлена программной заглушкой. Полноценная интеграция с банковскими сервисами пока не реализована.

При разработке были выявлены следующие ограничения:

- **URI-схемы банковских приложений:** Прямые переходы по ссылкам вида `tbank://` могут не поддерживаться или блокироваться Telegram-клиентом.
- **Ограничения мобильных ОС:** Автоматический запуск банковских приложений через промежуточные веб-страницы может ограничиваться политиками безопасности Android, браузера или банковского приложения.

## Статус проекта
**Разработка временно приостановлена.**

Реализованы основные механизмы регистрации пользователей, управления профилями, взаимодействия с базой данных и обработки состояний диалога.

## Запуск проекта
Для локального запуска приложения необходимо подготовить окружение, собрать проект и настроить переменные окружения.

### 1. Подготовка окружения
Для работы с проектом необходимы:

- Java 21
- PostgreSQL
- Apache Maven

Проверить установленные версии Java и Maven:

```bash
java -version
mvn -version
```

Перед запуском приложения убедитесь, что PostgreSQL запущен, необходимая база данных создана, а параметры подключения соответствуют конфигурации проекта.

### 2. Сборка проекта
Для сборки используется Apache Maven, установленный в операционной системе.

Перейдите в корневую директорию проекта, содержащую файл `pom.xml`, и выполните команду:

```bash
mvn clean package
```

Для сборки без запуска тестов:

```bash
mvn clean package -DskipTests
```

После успешной сборки JAR-файл будет находиться в директории `target/`.

### 3. Настройка переменных окружения
Для запуска приложения необходимо определить две переменные окружения:

| Переменная | Назначение |
|:---|:---|
| `DB_PASSWORD` | Пароль для подключения к PostgreSQL |
| `BANK_BOT_KEY` | Токен Telegram-бота |

Конфиденциальные данные передаются через переменные окружения и не должны храниться непосредственно в исходном коде.

Файл `.env` в проекте не используется.

### 4. Запуск через IntelliJ IDEA
При локальной разработке переменные окружения задаются непосредственно в конфигурации запуска IntelliJ IDEA.

1. Откройте проект в IntelliJ IDEA.
2. Перейдите в **Run → Edit Configurations**.
3. Выберите конфигурацию запуска Spring Boot приложения.
4. Откройте раздел **Environment variables**.
5. Добавьте две переменные:

   | Name | Value |
      |:---|:---|
   | `DB_PASSWORD` | Пароль от PostgreSQL |
   | `BANK_BOT_KEY` | Токен Telegram-бота |

6. Сохраните конфигурацию.
7. Запустите приложение через IntelliJ IDEA.

Переменные окружения будут переданы процессу приложения автоматически при запуске из выбранной конфигурации IDE.

**Важно:** Не добавляйте конфигурации запуска с реальными паролями и токенами в систему контроля версий.

### 5. Запуск через терминал
Приложение также можно запустить через терминал, используя собранный JAR-файл.

Переменные окружения, заданные только в конфигурации IntelliJ IDEA, автоматически не передаются в отдельный терминал.

#### Windows (PowerShell)
Задайте переменные окружения и запустите приложение:

```powershell
$env:DB_PASSWORD='ПАРОЛЬ_ОТ_БД'; $env:BANK_BOT_KEY='ТОКЕН_БОТА'; java -jar target/имя-файла.jar
```

#### Linux / macOS (Bash)
Передайте переменные окружения непосредственно при запуске:

```bash
DB_PASSWORD='ПАРОЛЬ_ОТ_БД' BANK_BOT_KEY='ТОКЕН_БОТА' java -jar target/имя-файла.jar
```

Если переменные окружения уже определены в текущем терминальном окружении, достаточно выполнить:

```bash
java -jar target/имя-файла.jar
```

Замените `имя-файла.jar` на фактическое имя исполняемого JAR-файла из директории `target/`, а значения переменных — на свои учётные данные.
